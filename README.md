##  🖼️ Interactive Image Map (HTML)

A simple HTML project that uses an image map to create interactive clickable areas within an image. Each section of the image links to a different webpage.

## Features
 
Displays an image with multiple clickable regions

Each region links to a different page

Demonstrates the use of the <map> and <area> tags

Beginner-friendly and easy to understand

## Built With
 
HTML

## How It Works
 
An image is displayed on the webpage

A map is created using the <map> tag

Clickable areas are defined using <area>

Each area links to a different destination when clicked

## How to Run
 
Download or clone the repository

Open the index.html file in your browser

Click on different parts of the image to navigate

How to use image maps in HTML

How to create interactive elements on a webpage
